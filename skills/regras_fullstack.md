# Diretrizes da Stack Principal

- **Frontend:** Use sempre componentes funcionais do React. Mantenha os estilos escopados e adote boas práticas de layout fluido.
- **Backend:** Em Node.js/Express, padronize as respostas da API em formato JSON e implemente *middlewares* globais para captura de exceções.
- **Revisão:** O @qa deve sempre rodar mentalmente o fluxo de execução para prever perdas de estado no React ou chamadas bloqueantes e não resolvidas no Node.js.
